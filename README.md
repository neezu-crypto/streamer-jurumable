# 스트리머 주루마블

방송 진행자가 브라우저에서 주사위를 굴리고, OBS 브라우저 소스에 같은 24칸 보드와 도착 안내를 실시간으로 보여주는 게임입니다.

## 현재 구현

- 참가자는 1~4명이며, 게임 시작 때 차례를 무작위로 섞습니다.
- 참가자 말은 출발 칸에서 시작합니다. 주사위는 약 2초간 굴린 뒤 결과를 표시합니다.
- 보드 칸에는 벌칙 이름만 표시하고, 상세 안내는 진행자 모달과 OBS 화면에 띄웁니다.
- 방어권 아이템의 지급·보유 상한·공격 방어 시 소모를 처리합니다.
- 시청자 지목과 술 마시기 공격 대상에 참가자와 스트리머를 표시합니다.
- 기본 보드 항목을 드래그하거나 선택해 칸을 교체합니다. 이름과 안내, 효과가 함께 바뀝니다.
- OBS 주소는 `?room=<방 코드>&view=1&key=<읽기 키>` 형식이며 보드는 투명 배경으로 표시됩니다.

## 로컬 확인

저장소 폴더에서 실행합니다.

```sh
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 열어 진행자 화면을 확인합니다. Firebase 익명 인증이 연결되면 `새 게임 방 만들기`를 눌러 방을 만들 수 있습니다. OBS가 접근할 수 있는 배포 주소를 브라우저 소스에 넣어야 다른 기기에서도 보드가 연결됩니다.

## Firebase 구조

- Cloud Functions codebase: `jurumable`
- 함수: `jurumableCreateRoom`, `jurumableUpdateRoom`, `jurumableGetRoomState`
- RTDB 경로: `streamerJurumable/rooms/{roomId}`
- OBS는 읽기 키를 검증하는 서버 함수를 1초마다 호출하고, 바뀐 상태만 받아옵니다. 진행자 상태 쓰기도 서버 함수만 수행합니다.
- 공유 RTDB 규칙은 수정하지 않습니다. 이 저장소에도 별도 규칙 사본을 두지 않습니다.
